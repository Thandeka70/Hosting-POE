# De Luna Apartments — HOSTING (WEDE5020 Portfolio Part 3)

Welcome to the official web application repository for **De Luna Apartments**, a luxury boutique guesthouse based in Bethlehem, Free State. This repository contains the complete responsive HTML5, CSS3, and interactive JavaScript front-end implementation designed to deliver an intuitive guest booking experience, showcase local attractions, and streamline direct host communications.

---

## 📌 Project Overview

The De Luna Apartments website provides prospective guests with an end-to-end digital touchpoint to explore accommodation offerings, review direct booking incentives, check local tourist highlights around Bethlehem and Clarens, interact with dynamic visual elements, and submit reservation requests.

---

## ✨ New Features & Dynamic Enhancements

### 1. Interactive FAQs & Content Accordion
- **Collapsible Sections:** Multi-item accordions allowing guests to toggle operational policies, check-in instructions, and frequently asked questions without cluttering the page view.
- **Dynamic State Toggles:** Smooth CSS height transitions and ARIA state updates for enhanced accessibility.

### 2. Interactive Google Maps Accordion
- **Interactive Location Hub:** Integrated map interface paired with an accordion sidebar to seamlessly toggle between destination highlights, physical address maps, and route directions around Bethlehem and Clarens.

### 3. Lightbox Gallery & Image Viewer
- **Full-Screen Media Inspection:** High-resolution modal pop-ups for apartment imagery and amenity photos.
- **Keyboard & Click Controls:** Overlay backdrop dismiss, close button hooks, and image switching logic driven by custom JavaScript events.

### 4. Interactive Search Bar & Dynamic Filtering
- **Real-Time Input Matching:** Live DOM filtering enabling users to search across room features, local attractions, and guesthouse amenities dynamically.
- **Empty State & Feedback:** Clear visual feedback when queries yield no matching results.

---

## 🛠️ Technology Stack & Architecture

- **Markup:** HTML5 (Semantic elements, accessible form structures)
- **Styling:** Custom CSS3 (Flexbox, CSS Grid, CSS Variables, Animations & Transitions)
- **Scripting:** Vanilla JavaScript (ES6+ DOM manipulation, Event Listeners, State Management)
- **Mapping:** Google Maps Embed API & Interactive Accordion Routing

---

## 📄 Site Structure & Page Breakdown

- **Home (`index.html`):** Brand landing page highlighting guesthouse amenities, visual hero section, and interactive search interface.
- **About Us (`about.html`):** Brand story, hospitality commitments, and collapsible FAQ accordion sections.
- **Apartments & Services (`apartment.html`):** Detailed room descriptions, amenity lists, and full-screen Lightbox image gallery.
- **Contact Us & Location (`contact.html`):** Address details, direct WhatsApp/Email links, and the Google Maps location accordion.
- **Nearby Attractions (`attractions.html`):** Regional highlight cards (Lions Rock, Ash River Outfall, Clarens Xtreme, Golden Gate National Park) with search/filter features.
- **Book Now (`book.html`):** Reservation form featuring interactive validation, room selection, date pickers, and direct booking benefit cards.
